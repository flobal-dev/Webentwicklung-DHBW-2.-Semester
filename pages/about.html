Über Cocktailpedia

Cocktailpedia ist ein kollaboratives Cocktail-Lexikon, entwickelt im Rahmen des Web-Entwicklung-Moduls im 2. Semester an der DHBW Lörrach. Ziel war es, eine übersichtliche, datengetriebene Plattform mit sauberem Frontend-Code und guter Usability zu bauen — inspiriert vom Prinzip Wikipedia, aber für Cocktails.

Tech Stack

HTML5 CSS3 Vanilla JavaScript Bootstrap 5.3 JSON
